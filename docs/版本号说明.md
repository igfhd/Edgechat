### 推荐的升级版本号操作方式：
可以直接手动修改 package.json 的 "version"（如改成 "1.1.0"），或者使用标准命令：
```
  # 自动同步更新 package.json 与 package-lock.json（推荐）
  npm version 1.1.0 --no-git-tag-version

  # 或者升级小版本（patch 补丁: 1.0.1）
  npm version patch --no-git-tag-version

  # 或者升级次版本（minor 特性: 1.1.0）
  npm version minor --no-git-tag-version
```

  如果你希望在 Git 上一并打出对应的 Release Tag，还可以执行：
```
  git tag -a v1.1.0 -m "Edgechat v1.1.0"
  git push origin v1.1.0
```
